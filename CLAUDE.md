# Project Cheat Sheet for Claude

## 🛠️ Build & Development Commands
* **Install dependencies:** `npm install` (or `pip install -r requirements.txt`)
* **Run local dev server:** `npm run dev`
* **Run linter:** `npm run lint`

## 🧪 Testing Commands
* **Run all tests:** `npm test`
* **Run a single test:** `npm test -- path/to/test.file`

## 📁 Codebase Structure Quick Reference
* `src/` — Core application code (controllers, models, services)
* `tests/` — Automated test suites
* `docs/` — System architecture and documentation

## 💡 Style & Workflow Rules
* Use descriptive variable and function names.
* Keep functions small and modular (Single Responsibility Principle).
* Maintain consistency with existing file naming conventions (e.g., camelCase or kebab-case).
